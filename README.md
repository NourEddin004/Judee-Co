# JUDE Boutique

The online store of JUDE Boutique: hijabs and clothing sets, in English and Arabic, with cash on
delivery across Jordan. Built by RafaqTech with Laravel 13, Filament 5, PHP 8.5 and MySQL 9.7.

- The store: `/`. Both languages share each address; the العربية / English button switches the language and keeps the address (old `/ar/...` links redirect).
- The admin panel: `/admin`.
